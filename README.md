# CafeFinder

Приложение для поиска заведений через OpenStreetMap и ведения списка потенциальных клиентов.

## Файлы
- `index.html` — интерфейс.
- `api/search.js` — поиск по городу через Overpass API.
- `api/check.js` — проверка доступности указанного URL.
- `package.json` — метаданные проекта.
- `vercel.json` — настройки Vercel Functions.

## Запуск и публикация
1. Загрузите все файлы и папку `api` в один GitHub-репозиторий.
2. Импортируйте репозиторий в Vercel.
3. Нажмите Deploy.
4. Откройте адрес проекта Vercel.

Зависимости npm не требуются (Node.js 18+).

## Важно
- Источник данных — OpenStreetMap/Overpass. Телефоны и сайты есть не у всех объектов.
- Пустое поле `website` означает только, что сайт не указан в OpenStreetMap. Это НЕ доказывает, что сайта нет.
- `/api/check` проверяет доступность URL, но не подтверждает, что сайт официальный и принадлежит заведению.
- База и избранное сохраняются в `localStorage` браузера на конкретном устройстве. Это не общая облачная база.
- Режим «Вся Россия» сейчас проходит по списку 16 крупных городов из интерфейса, а не по всей территории России.
- Для надёжной защиты от SSRF в публичном сервисе дополнительно нужна DNS-проверка IP-адреса назначения на сервере и проверка каждого редиректа.
